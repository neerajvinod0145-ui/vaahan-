# VahanaShare – Bike and Vehicle Sharing System

A beginner-friendly frontend prototype for a bike and car sharing/rental website.

## Features
- Responsive home page
- Bike and car listings
- Search by vehicle name or type
- Filter by Bikes or Cars
- Booking form with date validation
- Estimated rental cost
- My Bookings section
- Cancel booking
- Saves bookings in browser localStorage

## Technology
- HTML
- CSS
- JavaScript

## How to run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Browse vehicles and try making a booking.

No installation or build command is required.

## Important project note
This is a frontend demonstration. Bookings are stored only in the current browser using localStorage. There is no backend server, shared database, real authentication, payment processing, or live vehicle availability. Data does not automatically sync between devices or users.

## Customize
Edit the `vehicles` array near the bottom of `index.html` to change vehicle names, types, descriptions, and daily prices.
